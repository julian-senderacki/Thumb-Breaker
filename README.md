# Thumb-Breaker
It's a split, columnar keyboard running the Colemak layout. The key sizes will be adjusted specifically to the size and length of my fingers, so that the setup is as optimal as possible. The visual design is not final yet, but I will be aiming for a mostly white look with a few custom-painted and custom-shaped keys.

The project is made for hackclub "Fallen" event, i don't have any expieriency with hardware,( i wielded once but it was long time ago) so i hope that i will be abe not to absolutly destroy this project.
